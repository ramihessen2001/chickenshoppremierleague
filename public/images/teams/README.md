# Team logos

Drop one PNG per team here, named after the team's slug:

    falcons.png  ->  team with slug "falcons"

That path (`/images/teams/<slug>.png`) is the fallback the site uses when a
team's `logo_url` column is empty, so a correctly named file needs no database
change. To use a different path or a hosted image, set `logo_url` on the team
row instead.

The files currently here are last season's crests, kept only so the convention
is visible. Replace them with this season's teams.
