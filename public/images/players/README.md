# Player headshots

Drop a portrait in here named after the player, lowercase with hyphens:

    Yaseen Jawhar   ->  yaseen-jawhar.jpg
    Hamza H. Abdushaheed -> hamza-h-abdushaheed.jpg

`.jpg`, `.jpeg`, `.png` and `.webp` are all tried, in that order, so the
extension does not matter. Nothing else is required — the profile picks the
file up on its own, and shows the player's initials until one exists.

Square crops look best; the profile renders them at 96px, so 400x400 is plenty.

To point a player at a file that does not follow the naming rule, set their
`headshot_url` from the pencil icon on the roster. That always wins.
